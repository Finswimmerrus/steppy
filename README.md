# Steppy Android

Нативный Android-прототип приложения персональных шаговых челленджей из `agents.md`.

Текущий статус: интерактивный UI-прототип с реальным подключением Health Connect и локальными демонстрационными данными. Это ещё не функционально завершённый MVP из acceptance criteria `agents.md`, поскольку backend и серверный rules engine не реализованы.

## Что реализовано

- нативный интерфейс на Kotlin и Jetpack Compose;
- onboarding и consent-first подключение Health Connect;
- чтение агрегата шагов за текущий день;
- экран «Сегодня»: текущая дата, горизонтальная неделя, персональная цель, прогресс и статус синхронизации;
- нижняя навигация: «Сегодня», «Мои игры», «Поиск», «Создать»;
- список активных и завершённых челленджей;
- поиск открытых челленджей по названию;
- создание локального черновика челленджа любым пользователем;
- профиль, открываемый нажатием на иконку маскота на экране «Сегодня»;
- экранные представления Активных, Усиленных и Свободных дней;
- рабочий визуальный ассет маскота Steppy: жёлтый округлый персонаж, белая повязка с `S`, кроссовки;
- demo-режим для устройств без Health Connect;
- безопасный тестовый режим без денег и необратимого выбывания.

## Что проверено

- Gradle-сборка `assembleDebug` проходит успешно;
- APK устанавливается на эмулятор Pixel 7 с Android 15;
- холодный запуск `MainActivity` проходит без crash-записей;
- Health Connect permission flow и чтение дневного агрегата подключены на уровне Android-клиента.

## Запуск

1. Откройте проект в Android Studio.
2. Дождитесь Gradle Sync.
3. Выберите созданный эмулятор `Steppy_Pixel_API_35` или физическое устройство.
4. Запустите конфигурацию `app` на Android 9 (API 28) или новее.

Сборка из терминала:

```powershell
.\gradlew.bat assembleDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

На Android 14 Health Connect встроен в систему. На Android 9–13 требуется приложение Health Connect из Google Play. Для публикации в Google Play необходимо заполнить Health Apps declaration и добавить публичную privacy policy.

## Текущие ограничения

Данные челленджа сейчас предоставляет локальный demo repository. Кнопка создания формирует только UI-состояние черновика и не публикует челлендж. Официальные результаты, goal snapshot, anti-fraud, enrollment, уведомления, idempotent sync и ledger должны приходить из backend API. Денежный режим намеренно не включён: соответствующие юридические, платёжные и timezone/day-boundary решения в `agents.md` имеют статус TBD.
